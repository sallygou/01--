# 早鸟票公共仓（教学模拟）

这是《多人 AI Agent 协作工作区设计》课程作业中的**公共仓**，项目背景为早鸟票活动平台。

## 定位

公共仓是团队所有成员共享的"中央枢纽"，负责共享规则、任务流转、知识沉淀和整体进度：

- 存放协作契约、成员名册、推进管理等**团队级共识文件**
- 通过**交换区 + 三种单据**实现成员之间任务的传递与交接
- 通过**知识区（静态/动态）**沉淀可复用的经验与资料
- 通过**提示词库**沉淀有效的 Agent 提示词

## 目录结构

| 目录 | 用途 |
| --- | --- |
| 00-推进管理/ | 推进计划、任务看板（预留）、会议纪要 |
| 01-成员名册/ | 团队成员及分工登记 |
| 02-协作契约/ | 协作契约 v1、三种单据模板、六件式任务包模板 |
| 03-知识区/ | 静态知识 / 动态知识（current + history）、索引（预留） |
| 04-交换区/ | 跨成员传递任务包与单据的唯一中转通道 |
| 05-提示词库/ | 经过验证的 Agent 提示词模板 |
| 88-工具箱/ | 常用脚本、工具与使用说明（暂为空位） |
| 99-归档/ | 已完成或废弃内容的归档 |

## 核心规则速览

1. 跨成员传递一律走 `04-交换区/`，必须附带协同单/回执单/退回单。
2. 任务以六件式任务包为单位流转。
3. 个人产出未经审核不得直接成为正式公共知识。

详见 `02-协作契约/协作契约-v1.md`。
