# 早鸟票公共仓（教学模拟）

这是《多人 AI Agent 协作工作区设计》课程作业中的**公共仓**。

## 定位

公共仓是团队所有成员共享的"中央枢纽"，由团队共同维护：

- 存放协作契约、成员名册、推进管理等**团队级共识文件**
- 通过**交换区**实现成员之间任务的传递与交接
- 通过**知识区**沉淀可复用的经验与资料
- 通过**提示词库**沉淀有效的 Agent 提示词

## 目录结构

| 目录 | 用途 |
| --- | --- |
| 00-推进管理/ | 项目推进计划、进度跟踪、会议纪要 |
| 01-成员名册/ | 团队成员及各人 Agent 的登记信息 |
| 02-协作契约/ | 团队协作规则、单据规范、交接流程 |
| 03-知识区/ | 沉淀可复用的知识、经验、结论 |
| 04-交换区/ | 成员之间传递任务包与交付物的中转站 |
| 05-提示词库/ | 经过验证的 Agent 提示词模板 |
| 88-工具箱/ | 常用脚本、工具与使用说明 |
| 99-归档/ | 已完成或废弃内容的归档 |
