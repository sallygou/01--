# 04-交换区

成员之间传递任务包与交付物的中转站，是唯一允许跨成员放置文件的区域。

## 流转规则（对应协作契约 v1）

1. 任何放入交换区的内容必须附带**协同单**（Markdown + YAML 头），模板见 `../02-协作契约/单据模板/`。
2. 接收方确认后放**回执单**；不符合要求则放**退回单**，由发起方取回修正。
3. 任务以六件式任务包为单位流转，领取后将任务包移入自己个人仓的 `01-输入/`。
4. 交接完成后，发起方应及时把已完成的单据和任务包移走或标记完成，避免堆积。

## 建议布局

- `待领取-发起人-接收人/`：等待对方领取的任务包与协同单
- `已完成-日期/`：交接完成后的单据存根（定期移入 `../99-归档/`）
