# 03-知识区

沉淀团队可复用的知识，分为静态与动态两类：

- `静态知识/`：稳定不变的规范、背景资料、术语表（修改须留变更记录）
- `动态知识/`：持续更新的成果归集
  - `动态知识/待审核/`：入库前暂存，**未审核的内容不是正式知识**
  - `动态知识/current/`：每类成果只保留当前有效版本
  - `动态知识/history/`：被替换的旧版本，按日期存放
- `索引-预留.md`：三本索引与双向引用的预留位置

## 入库铁律

**个人产出未经审核不得直接成为正式公共知识**，须经协作流转或他人确认后才能入库。
每篇入库内容注明来源、日期、作者，动态知识还需标注关联任务包。
