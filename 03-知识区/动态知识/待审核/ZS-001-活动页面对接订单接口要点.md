# 活动页面对接订单接口的字段清单与返工点

> ⚠️ 文中接口数据为教学模拟数据，但"字段清单与常见返工点"部分具备复用价值。

## 一、活动页面下单需准备的字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| user_id | string | 用户唯一标识 |
| ticket_type | string | 票种编码 |
| quantity | int | 购买数量（1-5） |
| idempotency_key | string | 幂等键，24 小时有效 |
| source_page | string | 来源页面，用于渠道统计 |

## 二、返回需处理的字段

`order_id`（订单号）、`status`（CREATED / PAY_PENDING）、`expire_at`（支付截止时间）。

## 三、常见返工点（经验总结）

1. **幂等键缺失**：页面重复提交会生成重复订单，必须在首版就把幂等键纳入必填。
2. **错误码未分类处理**：库存不足（40901）与限频（42901）的提示文案不同，混为一谈会导致体验问题。
3. **忽略调用频率上限**：活动类页面峰值容易触发限频，上线前必须确认 QPS 是否满足。
4. **支付截止时间未展示**：返回中的 `expire_at` 若不在页面倒计时，用户容易流失。
