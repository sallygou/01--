# 六件式任务包模板

每个任务包是一个目录，命名规则：`任务包-日期-主题`（如 `任务包-20261029-票种定价调研`）。
目录内包含以下六个 Markdown 文件，每个文件都很短，写清楚即可。

```
任务包-YYYYMMDD-主题/
├── 01-任务说明.md    背景是什么、要达成什么、边界在哪里
├── 02-输入清单.md    依赖哪些资料、接口、他人产出；缺失项明确标注
├── 03-执行计划.md    步骤、分工、时间点
├── 04-产出清单.md    交付物列表、格式要求、验收标准
├── 05-协作记录.md    相关协同单/回执单/退回单的编号与状态，按时间排列
└── 06-沉淀归档.md    成果最终去向（知识区/归档）、可沉淀的知识点
```

## 各件最小格式示例

**01-任务说明.md**
```
- 背景：
- 目标：
- 范围内：
- 范围外：
```

**02-输入清单.md**
```
| 输入 | 来源 | 状态 |
| --- | --- | --- |
| {资料/接口名} | {路径或负责人} | 已具备 / 缺失 |
```

**03-执行计划.md**
```
| 步骤 | 负责人 | 计划完成时间 |
| --- | --- | --- |
```

**04-产出清单.md**
```
| 产出 | 格式 | 验收标准 |
| --- | --- | --- |
```

**05-协作记录.md**
```
| 日期 | 单据编号 | 方向 | 状态 |
| --- | --- | --- | --- |
```

**06-沉淀归档.md**
```
- 成果去向：
- 值得沉淀的知识点：
- 归档时间：
```
