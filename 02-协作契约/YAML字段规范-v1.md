# YAML 字段规范 v1

本文件是三种单据、交付物、验收结论与知识条目的**唯一字段标准**。校验脚本以此为判定依据。
所有规范文档（含本文件）本身豁免字段校验。

## 1. 通用必填字段（所有受控结构化文档）

| 字段 | 必填 | 合法取值 / 格式 | 说明 |
| --- | --- | --- | --- |
| 类型 | 是 | `协同单` / `回执单` / `退回单` / `交付物` / `验收结论` / `动态知识` / `静态知识` | 决定后续所有约束 |
| 状态 | 是 | `草稿` / `已发出` / `已接收` / `进行中` / `待验收` / `已完成` / `已退回` / `已归档` / `已作废` | 统一状态字典 |
| 创建日期 | 是 | `YYYY-MM-DD` | 建单日期 |
| 更新时间 | 是 | `YYYY-MM-DD` | 最后一次实质修改 |

除 `类型` 外的取值由程序校验；`类型` 之外的业务内容（方案是否正确）**不属于结构校验范围**，由人或 AI 判断。

## 2. 单据编号 vs 文档编号

| 文档类别 | 编号字段 | 格式 |
| --- | --- | --- |
| 协同单 / 回执单 / 退回单 | `单据编号` | `类型-YYYYMMDD-NNN`，如 `协同单-20261029-001` |
| 交付物 / 验收结论 / 动态知识 / 静态知识 | `文档编号` | `前缀-YYYYMMDD-NNN`，如 `DOC-20261029-001`、`VR-20261029-001`、`ZS-001` |

编号必须全团队唯一（允许"交换区原件 + 个人仓 `01-输入/` 留痕副本"成对出现，其余重复一律报错）。

## 3. 关系与人员字段

| 字段 | 适用于 | 约束 |
| --- | --- | --- |
| 发起人 | 协同单 / 回执单 / 退回单 | 必填，必须在成员名册中 |
| 接收人 | 协同单 / 回执单 / 退回单 | 必填，必须在成员名册中，且不得与发起人相同 |
| 负责人 | 交付物 / 验收结论 | 必填，必须在成员名册中 |
| 作者 | 动态知识 / 静态知识 | 必填，必须在成员名册中 |
| 任务包 / 任务编号 / 来源任务包 | 全部 | 至少一个非空；指向的任务包必须真实存在 |
| 关联文件 | 全部 | 可选，但列出的路径必须真实存在 |
| 回复的协同单 | 回执单 | 必填，目标协同单必须存在 |
| 针对的协同单 | 退回单 | 必填，目标协同单必须存在 |
| 审核人 / 审核结论 | 动态知识 | 入库到 `current/` 前必填；审核人须在名册且 ≠ 作者；审核结论取 `通过` / `退回` |

> 注：`回执人`、`退回人` 已统一为 `发起人` + `接收人`；`回执日期`、`退回日期` 已统一为 `创建日期` + `更新时间`。

## 4. 目录合法性规则

| 文档类型 | 允许落位 |
| --- | --- |
| 协同单 / 回执单 / 退回单 | 公共仓 `04-交换区/**`、个人仓 `01-输入/**`（留痕副本） |
| 交付物 / 验收结论 | 个人仓 `03-生效区/**`、公共仓 `03-知识区/动态知识/待审核/**` |
| 动态知识 | 公共仓 `03-知识区/动态知识/{待审核,current,history}/**` |
| 静态知识 | 公共仓 `03-知识区/静态知识/**` |

模板文件（`...-模板.md`）、说明书（`README.md`）、任务包六件免 YAML 头要求，落位不受上表约束。

## 5. 发布红线（程序强制）

进入 `03-知识区/动态知识/current/` 或 `history/` 的文件，必须同时满足：

1. 有 `审核人` 且审核人在成员名册中、且不等于 `作者`；
2. `审核结论: 通过`；
3. 在 `00-推进管理/审核记录-*.md` 中能查到该 `文档编号` 的审核记录。

任一不满足 → 视为"未经审核的错误发布"，**阻止提交**。
