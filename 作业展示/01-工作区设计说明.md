# 01-工作区设计说明

本文件说明「早鸟票活动平台」多人 AI Agent 协作工作区的实际设计，并给出第一部分的验收结论。
**所有结论均以本机真实文件与真实命令输出为依据**，如实区分「已实现 / 已模拟 / 仅有规则设计 / 尚未实现」。

---

## 一、物理结构：一个非 Git 总空间 + 三个独立 Git 仓

总工作空间 `ai多人协同工作台` **本身不是 Git 仓库**，仅作为三个仓库的共同父目录。

| 仓库 | 角色 | Git 目录（真实绝对路径） |
| --- | --- | --- |
| `01-早鸟票公共仓` | 团队中枢：规则、流转、知识、进度 | `C:/Users/13996/WorkBuddy/ai多人协同工作台/01-早鸟票公共仓/.git` |
| `02-张若彤个人仓` | 张若彤（活动平台）的独立工作室 | `C:/Users/13996/WorkBuddy/ai多人协同工作台/02-张若彤个人仓/.git` |
| `03-王小明个人仓` | 王小明（交易系统）的独立工作室 | `C:/Users/13996/WorkBuddy/ai多人协同工作台/03-王小明个人仓/.git` |

### 验收证据（真实命令输出）

```
# git -C <repo> rev-parse --absolute-git-dir / --show-toplevel
01-早鸟票公共仓   → git-dir 与 toplevel 均指向自身，HEAD = e6390f1（31 个受跟踪文件）
02-张若彤个人仓   → git-dir 与 toplevel 均指向自身，HEAD = 6e56aab（16 个受跟踪文件）
03-王小明个人仓   → git-dir 与 toplevel 均指向自身，HEAD = bcc856a（17 个受跟踪文件）

# 最外层
git rev-parse --show-toplevel
→ fatal: not a git repository (or any of the parent directories): .git
ls -d .git → No such file or directory

# 远程仓库
三个仓库 remote 数量均为 0，从未 push。
```

**结论：三个仓库彼此完全独立（各自的 `.git`、各自的提交链），最外层未被初始化，无远程、无推送。状态判定：已实现（已验证）。**

## 三、个人仓：各自独立的工作室

两个个人仓结构完全一致，成员角色不同：

| 目录 | 职责 |
| --- | --- |
| `AGENTS.md` | 本仓 Agent 行为约定：只在本仓工作、跨成员一律走交换区、产出未经确认不入公共知识区、重要操作在日志留痕 |
| `01-输入/` | 接收来自公共交换区的任务包与单据（含留痕副本） |
| `02-任务/` | 按六件式任务包开展当前工作 |
| `03-生效区/` | 已确认生效的产出（对外交付的来源） |
| `04-归档/` | 已完结任务包的整体归档 |
| `09-日志/` | 工作日志与 Agent 协作记录 |

**真实内容**：两个任务包 `ZRT-20261029-01`（张若彤）、`WXM-20261029-01`（王小明）各自以完整六件（01–06）存在，验收后已整体迁入 `04-归档/`。

**职责边界状态：规则层面已明确（三份 AGENTS.md + 协作契约第 2 节 + YAML 规范第 4 节目录表），并且已由程序部分强制（见 04 号文档 R8）；但 Git 本身不做目录级权限隔离——物理上仍可直接编辑他人文件。**

```
├── 动态知识/
│   ├── 待审核/         → 仅 README.md（阶段二增设的暂存区）

```

- **尚未实现**：静态知识无条目；三本索引未启用。
